Entry for [One Line, One Minute: The Vending Machine Pickup Line Contest](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee) on make.fun.

A single original pickup line, spoken by a vending machine itself to a
passing human — no exact change needed, just a smile, and the coil drops
something sweet on the house. The program writes that one line to
`/output/entry.txt`, deterministically, using only the Python standard
library.

## Run

```sh
python3 main.py
```

The line is written to `/output/entry.txt`, byte-identical on every run.
